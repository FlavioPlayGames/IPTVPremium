COMPARAR CATALOGOS API E M3U NO PC - SOMENTE LEITURA

Etapa seguinte a verificacao de capacidade. A API da conta ja foi confirmada pelo teste anterior, mas as contagens da ultima M3U e da API foram medidas em momentos diferentes. Nao comprovam equivalencia ou perda de conteudo. Antes de trocar o transporte, esta ferramenta consulta os tres catalogos API e a M3U na mesma execucao.
Pede o link get.php de forma oculta. Nao recebe credenciais na linha de comando. Nao grava links, nomes, credenciais, itens ou identificadores individuais no relatorio; usa apenas totais de conjuntos. Nao muda o aplicativo, o cadastro ou o catalogo da TV. Nao pede episodios pela API ou arquivos de video. A leitura de M3U e sequencial, guardando apenas conjuntos de titulos/IDs unicos; respostas JSON da API sao analisadas na RAM do PC, com limite de 64 milhoes de caracteres por endpoint. O PC pode usar memoria significativa. A TV nao participa.
Compara titulos com normalizacao Unicode FormKC, caixa e espacos; nao remove qualidade, ano, acentos ou outras palavras que poderiam colidir. Series M3U sao agrupadas pelo marcador SxxExxx. A classificacao considera sinais de caminho, grupo e metadados XUI/tvg-id, preservando grupos ao vivo/24H. Listas ambiguas podem ter entradas nao classificadas. Contagens por titulo nao distinguem necessariamente duas obras de mesmo nome; sobreposicao de xui-id e ID API nao prova que usem o mesmo namespace. coverageVerified permanece false. Nao e prova de equivalencia de URLs, disponibilidade de video, filtros, episodios ou todas as variantes de M3U. Mudancas do provedor durante a execucao tambem podem causar diferencas.
Relatorio: apiRows/m3uRows, titulos unicos de cada lado, comuns, exclusivos, entradas sem titulo, IDs unicos e sobreposicao; quantidade de episodios M3U, total de entradas, nao classificados e estado de conclusao. m3uRows de series conta entradas de episodio; m3uUniqueTitles indica agrupamentos distintos, nao um identificador remoto de serie.
Leitura truncada de JSON sem delimitador final e erro HTTP sao falhas, nunca cobertura confirmada. Erros sao registrados apenas por classe/status; mensagem de excecao pode conter URL e nao e publicada. M3U nao possui marcador final universal, portanto EOF nao prova por si so integridade do arquivo no provedor. A ferramenta nao toma decisao de migracao automaticamente.

Executar: powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Comparar-Catalogos.ps1
Cole o link no prompt oculto. Aguarde; baixar a M3U inteira depende do servidor e pode levar minutos. Pode manter a tela do computador; nao precisa abrir ou atualizar o aplicativo na TV. Envie somente comparacao-catalogos-<data>.json de Downloads.
Testes com servidor HTTP local e PowerShell: duplicatas, exclusivos dos dois lados, agrupamento de episodios, XUI sem extensao, canal com tvg-id vazio e grupo misto, comparacao de IDs, erro 403 e JSON truncado; saida sem host, credenciais, titulos ou URLs individuais. Teste com provedor real na rede do usuario ainda pendente.
