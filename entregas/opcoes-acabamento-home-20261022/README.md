# Seis opções de acabamento para os ícones da Home

Proposta visual para escolha; nenhuma alteração aplicada ao app.

1. Champanhe acetinado: dourado suave, interior marfim.
2. Ouro envelhecido: bronze escovado, interior chumbo.
3. Grafite fosco: cinza escuro, detalhes prateados.
4. Prata escovada: cinza médio, interior pérola.
5. Rosé acetinado: rosa queimado, interior cinza quente.
6. Azul petróleo: azul profundo, interior grafite.

A imagem é uma proposta de materiais, não uma captura do Android. O acabamento escolhido poderá ser adaptado às cinco cores existentes e aos modos Claro e Escuro.
